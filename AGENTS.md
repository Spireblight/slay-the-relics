# Slay the Relics

Slay the Relics is a Twitch Extension and Slay the Spire 1/2 mod to allow
viewers to interact with the streamers run live.

## Rules

- Frontend changes must pass the lint stage `yarn run lint`
- Backend changes must pass the lint and import stages `make lint` and `make imports`
